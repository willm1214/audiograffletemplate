# WELCOME
Audio Engineering Template for OmniGraffle

This is a working OmniGraffle template/stencil to make drafting System Block Diagrams, Network Diagrams, etc. easier for audio nerds like me!

To **_download_**, please see "Releases" to the right. Enjoy!      ->


# How to Install
Follow this file path:

    /Library/Containers/com.omnigroup.OmniGraffle7/Data/Library/Application Support/The Omni Group/OmniGraffle

Then drag and drop the template into the "Stencils" folder.

**_Where is the "Library" folder?_**

Open FINDER -> Go + Hold ALT Key -> "Library" will appear!

# Ive installed it but where do I find the objects in OmniGraffle?
Having opened a file, go to the bar on the right and click the waffle-looking icon. From there, you should find this template and click it. Still on the side bar, the list of objects should appear.
